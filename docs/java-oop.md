# Java e programmazione a oggetti

Java è un linguaggio compilato ed eseguito dalla Java Virtual Machine (JVM). Una variabile ha un tipo, per esempio `String` per il testo o `int` per un numero intero. Un metodo è un blocco nominato che può ricevere parametri e restituire un risultato.

Una classe descrive dati e comportamenti; un oggetto è un'istanza concreta creata da quella classe. Per esempio, `Attivita` può descrivere i campi titolo e completata, mentre una singola attività è un oggetto con valori specifici.

Concetti iniziali:

- **Incapsulamento:** proteggere lo stato e controllare come viene letto o modificato.
- **Interfaccia:** un contratto che dichiara operazioni senza fissare necessariamente la loro implementazione.
- **Composizione:** costruire una classe usando altre classi come collaboratori.
- **Collezione:** contenitore di più valori, per esempio `List<Attivita>`.

Procedi con esempi piccoli: prima crea un oggetto, poi una lista, poi metodi che leggono o modificano la lista.
